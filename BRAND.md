# MorviLabs brand kit (v0.1 — derived from the Editorial Engineering portfolio)

Use this for every MorviLabs-labelled asset (plugin READMEs, report footers, LinkedIn cover images, landing pages).

## Palette
| Token | Hex | Use |
|---|---|---|
| `--ink` | `#0a0d14` | Backgrounds, primary text on cream |
| `--paper` | `#f4f1ea` | Light backgrounds, text on ink |
| `--ember` | `#f0863a` | Single accent: links, badges, severity P0/P1, CTA |
| `--mist` | `#cfd6e4` | Secondary text on ink, rules, borders |
| `--slate` | `#8b93a7` | Tertiary text, metadata, timestamps |

Rule: one accent only. Never introduce a second saturated color. Severity levels use ember (P0/P1), mist (P2), slate (P3).

## Type
- Display / headings: **Playfair Display** (serif) — editorial feel.
- Body, code, terminal output, badges: **JetBrains Mono**.
- Arabic: **IBM Plex Sans Arabic** (pairs cleanly with Plex-weight mono; RTL-safe).

## Voice
- Senior-engineer register: concrete, short, no hype words ("revolutionary", "supercharge").
- Bilingual assets are Arabic-first, then English. Egyptian-professional Arabic, not MSA-stiff.
- Sign-off line on reports/READMEs: `— MorviLabs · built by Karim Adel`

## Wordmark
Plain text until a logo exists: `MorviLabs` in Playfair Display, ember dot after: **MorviLabs.**
Badge (shields.io): `https://img.shields.io/badge/MorviLabs-review--crew-f0863a?style=flat-square&labelColor=0a0d14`

## Don'ts
- No client names, revenue figures, or ship dates from day-job projects on any public MorviLabs asset.
- No gradients, no emoji in headings.
